# 🎵 YouTube MP3

YouTube videolarını ve playlist'leri MP3 olarak indiren, modern arayüzlü Pardus / Linux programı.

## Kurulum

1. **[ytmp3_3.3_all.deb dosyasını indir](https://raw.githubusercontent.com/orhankader80-beep/ytmp3/main/dagitim/ytmp3_3.3_all.deb)**
2. İndirilen dosyaya çift tıkla ve **Kur**'a bas.
3. Uygulama menüsünde **YouTube MP3** olarak çıkar.

> Pardus 23 ve üstü (Python 3.11+) gerekir.

## Özellikler

- Tek video veya playlist indirme, 128–320 kbps kalite seçimi
- MP3'e kapak resmi ve bilgi ekleme
- MP3'leri doğrudan USB belleğe kaydetme
- USB'ye taşınabilir kopya oluşturma
- Kişiselleştirme: renk, tema, yazı boyutu, adınla karşılama, dosya adı biçimi
- **🔄 Güncelle** butonu: hem programı hem indirme motorunu günceller

## Geliştirici için

- `paket/deb_olustur.sh` — .deb paketini oluşturur
- `paket/yayinla.sh "notlar"` — yeni sürümü yayınlar (`ytmp3.py` içindeki `VERSION` artırılmalı)

Not: Yalnızca indirme hakkınız olan içerikler için kullanın.
